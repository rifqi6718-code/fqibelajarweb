Belajar CSS

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan dan format elemen teks pada halaman web agar lebih menarik dan mudah dibaca. Dengan CSS, pengembang dapat mengubah berbagai aspek teks seperti warna (color), ukuran huruf (font-size), jenis font (font-family), ketebalan huruf (font-weight), perataan teks (text-align), serta jarak antar huruf dan baris. CSS juga memungkinkan pembuatan efek visual seperti bayangan teks (text-shadow) dan dekorasi seperti garis bawah (text-decoration). Dengan penggunaan CSS yang tepat, tampilan teks menjadi lebih konsisten, profesional, dan memberikan pengalaman pengguna yang lebih baik saat mengakses sebuah website.
