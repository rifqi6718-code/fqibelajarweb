CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan halaman web. Dengan CSS, kita dapat mengubah warna, ukuran teks, jenis huruf, jarak, dan tata letak elemen HTML agar halaman terlihat lebih menarik dan mudah dibaca.

CSS dapat ditambahkan langsung di dalam file HTML, ditulis pada file terpisah, atau diterapkan melalui atribut pada elemen. Penggunaan file CSS terpisah membantu menjaga kode tetap rapi dan memudahkan kita menerapkan desain yang konsisten pada beberapa halaman web.
